Salvage Settlers - Hosting & Deployment Guide

This guide explains how to host your real-time salvage e-auction portal live on the web to showcase it to clients.

Option A: Render.com using Docker (Recommended & Easiest)

Render supports deploying Docker containers for free. This is the best choice because it packages both Node.js (for the frontend/proxy) and Python 3 (for the database backend) into a single server seamlessly.

Step-by-Step Setup:

  1. Push the latest code (including the new Dockerfile) to your GitHub repository.
  2. Log in to your Render.com dashboard.
  3. Click New + $\rightarrow$ Web Service.
  4. Connect your GitHub repository.
  5. Render will automatically detect the Dockerfile. Set the following configurations:
    • Runtime: Docker
    • Instance Type: Free (or Starter for persistence)
  6. Click Advanced to add your Environment Variables (Secrets):
    • SMTP_HOST = smtp.gmail.com
    • SMTP_PORT = 587
    • SMTP_USER = (your Gmail account)
    • SMTP_PASS = (your 16-character Google App Password)
  7. Click Create Web Service. Render will build the container and deploy it live!
Note on Free Tier Persistence: Render's free tier spins down the server after 15 minutes of inactivity and clears the local SQLite database (vault.db) on restarts. For client demos where you want newly created lots to persist permanently, choose a Render Starter Instance with a persistent disk volume.

Option B: Railway.app (Automatic Deployment)

  1. Create an account on Railway.app.
  2. Click New Project $\rightarrow$ Deploy from GitHub Repo.
  3. Railway automatically detects the Dockerfile and deploys it.
  4. Add your SMTP credentials under the Variables tab in Railway.

Option C: DigitalOcean Droplet (Best for Production)

If you prefer a standard Linux Virtual Private Server (VPS) where your database is 100% persistent without paying for cloud database add-ons:

# 1. Update server packages
sudo apt update && sudo apt install -y nodejs npm python3 sqlite3 git nginx

# 2. Clone repository
git clone <your-repo-url>
cd real-time-auction-&-analytics-portal

# 3. Install packages and build Vite bundle
npm install
npm run build

# 4. Install PM2 process runner to run in background
sudo npm install -y pm2 -g
pm2 start "npm start" --name "salvage-portal"
pm2 save
